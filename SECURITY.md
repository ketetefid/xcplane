# Security Policy

## Reporting a vulnerability

If you discovered a security vulnerability in xcplane, please do not disclose it
publicly through a GitHub issue. Instead, report it privately through the
repository's security advisory mechanism.

Please include:

- a description of the vulnerability
- the affected component or version
- steps to reproduce the issue, if applicable
- the potential impact
- any suggested mitigation or fix

Disclosure with the reporter will be coordinated for the valid reports.

## Scope

Security issues involving xcplane itself, its Ansible automation, configuration
handling, credential management, remote server management, or integrations are
considered in scope.

For vulnerabilities in third-party software managed by xcplane, please also
consider reporting the issue to the relevant upstream project.
